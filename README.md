# metadata_web

A powerful web-specific metadata extraction implementation for Flutter, seamlessly integrating with web browsers to extract EXIF and media data.

## Features

- Extract EXIF metadata directly from web file instances
- Parse file types and sizes accurately on Flutter Web
- Built on top of `metadata_core` for standardized metadata models

## Getting started

Add `metadata_web` to your `pubspec.yaml`:

```yaml
dependencies:
  metadata_web: ^0.0.1
```

## Usage

```dart
import 'package:metadata_web/metadata_web.dart';

// Access web-specific extraction implementations
```
